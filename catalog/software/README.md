# Versões aprovadas — somente metadados

Este diretório começa **sem integrações aprovadas**. Não copiar o exemplo R1 incompleto ou fixtures fictícias para cá.

Cada arquivo `<id>.json` é um manifesto community v2 original, sem formato paralelo. A inclusão/alteração/remoção requer PR revisado e decisão humana na branch protegida. O gate de submissão não concede aprovação. Registre no PR revisores, decisão/data, versão/commit, evidências, limitações e hashes quando houver artefatos; preserve esse histórico nas atualizações e retiradas.

Referências locais são relativas à raiz do repositório e devem acompanhar a proposta. O gerador verifica documentos/imagens/hashes sem executar nada. Somente o índice JSON é publicado; documentos, fontes e artefatos não são copiados para Pages. O aplicativo não abre links nem busca imagens/artefatos deste índice.

Configuração, limites e revisão: [guia do catálogo](../../docs/public/CATALOG.md).
